1. Summary

NC OSBM (S9) owns the problem and sponsors one central tool for every agency, so it sits in Manage Closely as sponsor and owner, and the OSBM-run pilot (NC DHHS, NC DEQ and one smaller agency) depends on its decision. Day to day, the tool succeeds or fails with each agency's grants coordinator, the DHHS federal-grants coordinator (S1) and the DEQ grants coordinator (S19), who review their agency's daily shortlist and record Pursue / Maybe / Pass, while DHHS division program leads (S2) receive routed items and agency leadership (S3, S4, S20) decides whether to apply. Smaller agencies with limited grant capacity (S21) are the users the sponsor most wants to reach, but none has been named or interviewed yet, so one should be chosen and consulted before the pilot. NCDIT (S6) and the DHHS privacy and security office (S7) can approve or stop a pilot but have little reason to look at the prototype yet, so engage them early with the architecture and security diagrams and a plain list of known gaps (no sign-in, so the agency switcher is not access control; a connection string and keys instead of managed identity). Two dependencies sit outside state government: Grants.gov (S13), whose one daily pull feeds every agency, and the event Azure subscription (S11), which the team will delete after judging (deploy/99_teardown.sh), so OSBM needs to name an owner and host before any pilot.

All power, interest and attitude scores are team estimates (ASSUMED) until checked with the stakeholders themselves; see section 8.

9. Glossary

Stakeholder
Anyone who affects, or is affected by, the solution.
Power/interest grid
Mendelow's 2×2 matrix for deciding how closely to engage each stakeholder: Manage Closely, Keep Satisfied, Keep Informed, Monitor.
Onion model
Concentric rings showing how directly each stakeholder interacts with the product (Ian Alexander).
RACI
Responsible, Accountable, Consulted, Informed: who does what for each activity.
Champion / Supporter / Neutral / Sceptic / Blocker
Attitude scale, from an active advocate to an active opponent of the solution.
Agency profile
One file per agency in a standard template (agency/profiles/), built from the agency's strategic plan: goals and objectives with page citations, divisions, keywords and the name USAspending uses for the agency.
Statewide page
The web app's central view (/statewide) for a team such as OSBM: each agency's High and Medium matches, items closing soon, decisions, and opportunities that are strong matches for more than one agency.
Pass-through funds
Federal money that a state agency receives and passes on to local governments, utilities or community organizations.
ASSUMED
A team estimate not yet confirmed by the stakeholder.
