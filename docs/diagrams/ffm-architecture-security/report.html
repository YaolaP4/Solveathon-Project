1. Executive summary

Federal Funds Matchmaker helps the NC DHHS federal-grants coordinator find federal funding that fits the NCDHHS Strategic Plan 2023-2025. Every day at 11:00 UTC (6:00 AM Eastern Standard Time; 7:00 AM during daylight saving time) a Container Apps Job pulls all posted and forecasted Grants.gov opportunities (about 1,460) and scores each one from 0 to 100 against the plan's 20 objectives. The plan-alignment part of the score is a hybrid: half an Azure OpenAI embedding margin (closer to a plan objective than to ten unrelated fields such as defence, arts or physics) and half TF-IDF word similarity. For the top 45 records, Azure OpenAI also writes a short summary with two quotes that Python checks word for word. Staff use a Flask web app on Azure Container Apps to review the ranked shortlist and record Pursue / Maybe / Pass; the AI never sets the score, and a person makes every decision.

The security posture is reasonable for a prototype that holds almost only public data: the app uses HTTPS with HSTS, CSRF tokens, a strict Content-Security-Policy, secure cookies, spreadsheet-safe CSV export and a non-root container, and keys are kept as Container Apps secrets rather than in code or the image. The main gaps are the missing sign-in (T1, High), which lets anyone with the URL read and record decisions, and shared keys and ACR admin credentials instead of managed identity (T5, T6); the team has planned fixes for all three (Entra ID sign-in, Key Vault and managed identity), and they should be in place before any pilot with real staff.

How the daily job scores an opportunity (as built)

PartWhat the code doesEvidence
Total score (0-100)45% plan alignment + 25% keyword fit + 15% eligibility (state agency) + 10% time to apply + 5% funder history (USAspending.gov). Computed in Python; the AI cannot change it.src/matcher.py (DEFAULT["weights"], score)
Confidence bandHigh ≥ 55, Medium ≥ 45, Low below 45. The AI review can only lower a band one step, or move a record to "not eligible" with a verified quote.src/matcher.py (DEFAULT["bands"]), src/rationale.py (apply)
Plan alignment (hybrid)0.5 × embedding margin + 0.5 × TF-IDF similarity. The margin is the embedding similarity to each plan objective minus the best similarity to 10 short off-topic field descriptions (for example defence, arts, physics). The best objective becomes the matched goal.src/matcher.py (similarity, off_topic_anchors)
Without Azure OpenAITF-IDF similarity alone; AI summaries are skipped and the score breakdown says the meaning-based part is unavailable.src/matcher.py, src/rationale.py, src/aoai.py
How it was tunedOn the 1,037 live opportunities the qualifier had already screened, against whether the qualifier judged them on topic for DHHS: AUC 0.91 for the hybrid (76% of its top 50 on topic), against 0.84 for raw embedding similarity (54%) and 0.81 for TF-IDF alone (50%). These are AI reference labels used for tuning; precision@10 on fresh human labels is on the Evaluation page. Not re-measured for this report (A16).src/tune_semantic.py, docs/tuning_report.md, docs/finals_field_notes.md

10. Glossary

C4 model
A way to draw software architecture at four zoom levels: Context, Container, Component, Code.
Container (C4)
A separately running part of a system, such as a web app, a scheduled job or a database. Not the same as a Docker container, although here each one does run in a container.
Container Apps Job
An Azure Container Apps resource that starts a container on a schedule, runs it to completion and records whether it succeeded or failed.
Data-flow diagram (DFD)
A diagram of how data moves between people, processes and data stores. It is the basis of most threat models.
Trust boundary
A line where the level of trust changes, such as between the internet and the Azure subscription. Threats cluster where data crosses it.
STRIDE
Six threat types: Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, Elevation of privilege.
OWASP Top 10 for LLM Apps
A list of the most important security risks for applications that use large language models, such as prompt injection (LLM01).
Prompt injection
Text placed in a model's input that tries to make the model ignore its instructions.
Managed identity
An identity that Azure manages for a service, so it can reach other Azure services without a stored key or password.
Key Vault
An Azure service that stores secrets and keys and controls who can read them.
secretref
A Container Apps setting that passes a stored secret into the container as an environment variable without writing the value in configuration.
ETag (optimistic concurrency)
A version tag on a stored file. A save only succeeds if the file has not changed since it was read, so two people saving at once cannot overwrite each other.
CSRF token
A random value in each form that proves a submission came from the app's own page, not from another website.
Content-Security-Policy (CSP)
A browser rule that limits which scripts, styles and images a page may load. Here only the app's own files are allowed.
HSTS
HTTP Strict Transport Security: a header that tells the browser to use only HTTPS for the site from then on.
CSV (formula) injection
Text in an exported spreadsheet cell that starts with = and runs as a formula when opened. The export adds a leading apostrophe so it shows as text.
Embedding
A list of numbers that represents the meaning of a text, so similar texts can be compared.
Embedding margin
How much closer a listing is to a plan objective than to the nearest of 10 unrelated fields (such as defence, arts or physics). It stops long, generic announcements from looking like good matches.
TF-IDF
A word-count method of comparing texts. Here it is half of the plan-alignment signal, and the whole signal when Azure OpenAI is unavailable.
AUC
Area under the ROC curve: the chance that a randomly chosen relevant grant is ranked above a randomly chosen irrelevant one (0.5 = guessing, 1.0 = perfect).
Precision@10
Of the top 10 results, the share that a human labeler marked as relevant.
Zero Trust
A security approach: verify explicitly, use least privilege, assume breach.
Well-Architected Framework
Microsoft's five pillars for reviewing cloud workloads: Reliability, Security, Cost Optimization, Operational Excellence, Performance Efficiency.
NIST CSF 2.0
The U.S. cybersecurity framework with six functions: Govern, Identify, Protect, Detect, Respond, Recover. Tags such as PR.AA name categories within them.
MCSB
Microsoft cloud security benchmark. Control families used here: IM (identity), PA (privileged access), DP (data protection), LT (logging), DS (DevOps security).
